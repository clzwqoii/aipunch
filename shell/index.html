GitHub Actions 配置

          
        

        

          
云端执行端所需，配置一次即可

          
—

          
    
            
  1. Fork（复刻）本仓库：github.com/clzwqoii/aipunch → 右上角 Fork 按钮（或使用你已有的仓库）
    2. 
            
  2. 创建 PAT（CI 回写轮换票用）：点「打开令牌创建页」（已预选 repo + workflow 权限）→ Generate token（生成令牌）→ 复制（只显示一次）
    3. 
            
  3. 仓库 Secrets（机密）：Fork 的仓库 → Settings → Secrets and variables → Actions → New repository secret（新建仓库机密），逐个添加各平台凭证（名字与本应用一致，如 TRAE_REFRESH_TOKEN、QODER_REFRESH_TOKEN、WORKBUDDY_REFRESH_TOKEN、CODEARTS_REFRESH_TOKEN、AUTOCLAW_INTL_REFRESH_TOKEN 等）与上一步的 GH_PAT
    4. 
            
  4. 启用 Actions：仓库 Actions 页确认 checkin.yml 已启用（每日定时自动签到，无需启动本应用）
    5. 
            
  5. 本机安装 gh CLI 并运行 gh auth login（手动触发、同步、改定时需要；macOS：brew install gh，Windows：winget install GitHub.cli）
    6. 
            
  6. 本应用数据目录 config.json 设置 "repo": "你的用户名/aipunch"，点「检查配置」逐项验证（含定时 CI 启停与定时时间）
    7. 
          

        

        

          
          
          
        

      

    


    
    

      

        

          
部署到 Cloudflare Workers

          
        

        

          
粘贴 Cloudflare 凭证即可代部署（KV + 脚本 + Secrets + 定时），无需安装 wrangler

          

            
            

              

              

            

          

          

            
            
          

          
    
            
  1. 注册/登录 Cloudflare（免费版即可）：dash.cloudflare.com（界面默认英文，可不管语言照下面走）
    2. 
            
  2. 创建令牌：右上角头像 → My Profile（我的个人资料）→ API Tokens（API 令牌）→ Create Token（创建令牌）→ 模板列表选「编辑 Cloudflare Workers」（不带 via Tenant tag 后缀）→ Use template（使用模板）→ Continue to summary（继续）→ Create Token（创建令牌）→ 复制令牌（只显示一次）；也可点下方按钮直达
    3. 
            
  3. Account ID（账户 ID）三处任取其一：① 登录 dash.cloudflare.com 后看浏览器地址栏，dash.cloudflare.com/ 后面那串字母数字就是；② 点进任意域名，首页（Overview/概览）右侧栏 API 区；③ 左侧菜单 Workers & Pages 页右侧栏 API 区
    4. 
            
  4. 两个值粘贴到上方输入框，定时沿用「定时执行」的设置，点「部署」
    5. 
            
  5. 部署成功后点选 Cloudflare Workers 平台卡；「一键签到」会立即触发一轮验证（约 1-2 分钟出结果）
    6. 
          

          
凭证在本机 .env 留存，部署后重复操作无需重贴。
